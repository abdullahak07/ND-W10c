# COMP6013 Week 10 — Cloud Security Atlas

A Vercel-ready interactive lecture website built from the Week 10 Cloud Security deck.

## Concept
A full-width **Cloud Security Atlas** with:
- short visible explanations for live class delivery
- deeper detail hidden behind in-place flip cards
- interactive diagrams
- seven mini-games
- quick checks and an eight-question final quiz

## Coverage
- NIST cloud definition and five essential characteristics
- SaaS, PaaS and IaaS
- Public, private, community and hybrid cloud
- NIST cloud reference actors
- STRIDE and Cloud Security Alliance threats
- Data breaches, IAM, insecure APIs, vulnerabilities, account hijacking, insiders, APTs, data loss and due diligence
- Security as a Service
- OpenStack, Keystone, Nova, Glance and Swift

## Deploy
Static site. Import this repository into Vercel. No build command is required.
